Selected work

A mix of program monitoring and the reporting systems built to support it — all delivered for the Lagos State Ministry of Health, Directorate of Family Health & Nutrition.

Reporting system

Annual memo-tracking system

Directorate memos were tracked manually with no visibility into turnaround times or bottlenecks. Rebuilt the annual tracking workbook in Excel with dynamic summaries, KPI dashboards, and calculated turnaround-time columns.

Now the directorate's standard system for the year, giving supervisors a live view of where memos stand rather than a static log.

Workflow automation

Intern rotation scheduler

Rotation planning across five DFHN divisions (RH, YAH, Child Health, Nutrition, M&E) was a recurring manual exercise. Built a fully automated Excel system in Python (openpyxl) that handles weighted division assignments, a live daily briefing, data validation dropdowns, and a 40-row buffer for future interns.

Removed the manual reshuffling that used to happen every rotation cycle.

Presentation design

MNCHW Round 2 presentation rebuild

A dense, text-heavy source deck for the Lagos State MNCH Week Round 2 (2025) program needed to work for a state-level stakeholder audience. Condensed it into an 18-slide, infographic-led highlights deck using an automated slide-generation workflow, with a consistent forest-green and coral visual identity.

Data quality issues in the source data were flagged rather than papered over — a suspect population figure was marked with a styled placeholder instead of being reproduced.
